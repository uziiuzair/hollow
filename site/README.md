# Hollow product page

Static page for https://uziiuzair.com/software/hollow. A dedicated assets-only Worker named `hollow` on the route `uziiuzair.com/software/hollow*`. No build step. Run `pnpm install` once in this folder first.

Preview at http://localhost:8787/software/hollow:

```
pnpm dev
```

Deploy:

```
pnpm exec wrangler deploy
```
